## F-56, the Windows tool-answer stall

Symptom: on Windows only, the MCP server accepted a request and then
never answered. Six numbered probes on `exp/windows-stdio-probe` (#186,
a draft that never merges) closed it, with faulthandler stack dumps as
the measurement. Mechanism: the first parameterized query triggers
DuckDB's lazy `import pandas`; loading pandas loads numpy, whose bundled
OpenBLAS DLL runs a libgfortran constructor that calls `fstat(0)`; on
Windows the UCRT resolves `fstat` on a pipe through `PeekNamedPipe`, and
Windows serializes that call behind the SDK stdin reader's already
pending `ReadFile` on the same handle. The server blocks inside an
import, not inside the query (numpy issue 24290). Fix (#187):
`src/metricmine/server/__main__.py` imports pandas, numpy, and pyarrow
at startup, before `server.run(transport="stdio")`, guarded for
ImportError. Probes 3 to 5 suggested an 8 KB pipe-buffer boundary; that
was a coincidence of payload size and not the mechanism. Probe 6
measured V0 FAIL, V1 PASS at 47 ms; the fixed tree answers in 46 ms
(pwsh) and 63 ms (powershell) on the runners.

## F-57, the connector's platform-default encoding

Symptom: Path B failed on Windows at the connector's `check` for
`ourairports_airports`; after that was fixed, the retail sample passed
`check` but failed the D-33 digest gate. Mechanism: airbyte-source-file
0.3.15 passes `reader_options.get("encoding")` to `smart_open.open`;
unset, text opens in the platform's preferred encoding, UTF-8 on macOS
and Linux, cp1252 on Windows. `ourairports_airports` carries 1,310
non-ASCII lines whose UTF-8 bytes are not valid cp1252, so it raised;
the retail sample's pound signs mojibaked silently to `Â£`, which raised
nothing and changed the gold content, caught only by the digest gate.
Fix (#189, #190): every affected sample declares `"encoding": "utf-8"`
in `config/default.yaml`. The reverted misdiagnosis (#188) blamed the
file URL and passed the sample as `csv_path.as_uri()`; the plain path
already worked for five of six samples, and `as_uri()` broke every
sample because the connector rebuilt `file://` plus the scheme-stripped
url and opened the literal `/D:/a/...`. Reverted with `git revert`
inside #189. The class: a text file read without a declared encoding is
read in the platform's, and the silent case is worse than the loud one,
because only a content gate catches it.

## Method, as the arc and its follow-up taught it

A negative from a scoped search is not a negative: state the scope or do
not state the result. A gate must exercise the branch under test: a
reproduction that ran with the artifact already on disk short-circuited
before any network call, passed, and proved nothing. The verdict tier is
part of the design: a FAIL that was right under one premise stayed
after the same change made the premise false, until the file's own
docstring was read back. A strategic prompt is an artifact and the probe
rule reaches it: four defects on the F-58 branch originated in prompts,
and every one was caught by something reading the actual tree. And an
executing agent that reads the tree outranks an architect that reasons
about it.
