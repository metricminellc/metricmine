## What the audit found, and what this arc repaired

The audit walked all three entry points on both platforms from fresh
clones and measured every claim a reader can act on. Beyond the six
items the mandate opened with, it found that the front door's only
quickstart did not run on Windows and its recording sentence had been
false for four releases; that the docs map behind every "Read the docs"
button on the site had not changed in 48 pull requests and omitted the
operator's manual, the sources register, the sources explained, and the
adding-a-source walkthrough; that the `uv run mm <target>` rule the
guide stated covered six of the nineteen `make` targets the documents
use, with the general rule living only in the decision register and a
docstring; that the preflight could not run before the thing it checks
(every documented invocation went through `uv run`, and a direct run on
a system Python raised at `import duckdb` and printed nothing); that the
website's finding count was stale in four places and its repository had
no CI gate at all; and that the Arc 7 collapse had dropped four prepared
edits nobody tracked, with the v1.1.1 release notes describing the
prepared tree rather than the merged one. Every item is listed in the
project record; every repair is in the ladder below.
