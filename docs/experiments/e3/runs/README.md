# docs/experiments/e3/runs/

> Repo path: `docs/experiments/e3/runs/README.md`
> The committed evidence of the E3 experiment (`../KEY.md`, Section 8):
> one folder per attempt under `<arm>[-<model>]/<fixture>/a<NN>/`,
> copied from the gitignored outbox by the arm runner after its screen,
> with the record's repository paths relativized. Each folder holds the
> record (`record.json`), and when a draft was written the proposal
> (`proposal.json`), the judgment under arm `B` (`judgment.json`), the
> rendered draft (`draft.odcs.yaml`), and the agreement study
> (`agreement.json`); a failed-closed attempt holds the record and the
> raw response. Nothing here is edited by hand: a recording is evidence,
> and an em dash inside model-written text stays and is counted. The
> ledger beside this folder (`../ledger.jsonl`) is the index.
